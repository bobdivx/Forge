## 2024-05-16 - API Route Network Optimization & Promise Concurrency
**Learning:** Astro API routes can suffer from high latency when sequentially awaiting external gateway/network calls and database-driven file system IO lookups. Un-awaited promises for slow external requests (e.g. gateway metrics) can be initiated at the top of the handler (with dummy catch handlers to prevent uncaught exceptions) and awaited later, effectively parallelizing the network request with local database/computation work. Sequential file IO for arrays of items can be optimized by mapping to an array of Promises and then `await`ing them sequentially to preserve order while allowing concurrent initiation.
**Action:** When an API route fetches both external metrics and local project states, proactively initiate the external fetch at the top of the function as an un-awaited Promise. Use Promise array mapping for sequential iterations over DB rows that require async filesystem/network checks to trigger them concurrently.
