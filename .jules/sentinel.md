## 2024-05-18 - [Command Injection]
**Vulnerability:** Command Injection in API routes using `execSync` for shell execution. User inputs (e.g. `tail`, `id`) from request URL query parameters were directly interpolated into a shell string executed by `execSync` in `src/pages/api/docker-logs.ts` (`docker logs --tail ${tail} ${containerId}`).
**Learning:** Using `execSync` with unsanitized user inputs to form shell commands allows attackers to execute arbitrary shell commands on the server by injecting shell metacharacters like `;`, `&`, `|`, or backticks into the parameters.
**Prevention:** Always use `execFileSync` (or `spawn` / `execFile`) instead of `execSync` or `exec` when dealing with parameters derived from user input or external sources. Pass the arguments as an array to `execFileSync('command', ['arg1', 'arg2'])` so that the operating system handles the arguments directly without passing them through a shell interpreter, effectively neutralizing any shell injection attempts.
