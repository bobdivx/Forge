## 2025-02-23 - Astro DB full-table N+1 query optimization
**Learning:** In Astro DB (Drizzle ORM), removing N+1 `db.select()` queries inside a loop by fetching the entire table once `await db.select().from(Table)` is an effective optimization strategy, especially for small-to-medium tables typical of local state (like local repositories). Drizzle's `inArray` is alternative but can be problematic on types/versions, so the full fetch into a JS Map for O(1) lookups avoids both N+1 trips and complex where-clauses. Be aware that Astro DB exposes Drizzle ORM native features directly, meaning it is not necessary to separately install `drizzle-orm` in the `package.json` for operations like batch inserting arrays, but you may need to use `loadAstroDb()` to fetch the instance and schema appropriately.
**Action:** Always prefer fetching existing data into a JS Map when synchronizing lists of items to the DB, but avoid `package.json` modifications when using Astro DB since Drizzle is built-in.
