## 2024-05-24 - [CRITICAL] Command Injection in docker logs API
**Vulnerability:** User-controlled `containerId` and `tail` query parameters were being directly concatenated into a shell command string and executed via `execSync(command)`. This allowed arbitrary shell command execution if an attacker crafted malicious query parameters containing shell metacharacters like `;`, `|`, or `&&`.
**Learning:** Node.js `exec` and `execSync` spawn a shell by default to parse the command string, making them highly vulnerable to command injection if user inputs are concatenated. Even with validation, it is dangerous. `execFileSync` avoids the shell by passing arguments directly to the executable.
**Prevention:** Never use `exec` or `execSync` with dynamically constructed strings. Always use `execFile` or `execFileSync` (or similar array-argument APIs like `spawn`) with an array of arguments. Always rigorously validate and sanitize inputs (e.g. using regex `/^[a-zA-Z0-9_.-]+$/` for IDs and verifying they do not start with a `-` to avoid argument injection). Explicitly use `--` to mark the end of options. Ensure error messages do not leak system information.
