## 2026-05-17 - Accessible Dashboard Integration
**Learning:** In Ageton's Astro/Preact hybrid environment, standard accessibility updates (like `aria-hidden="true"` on decorative SVGs or `aria-controls`/`aria-expanded` on Preact stateful toggles) must bridge static Astro layouts (`DashboardLayout.astro`) and dynamic Preact islands (`MobileMenu.tsx`, `DashboardGitPullAllButton.tsx`). Screen readers handle this transition poorly if ARIA states in islands don't map to IDs predictably during client hydration.
**Action:** Always ensure ARIA attributes across the Astro/Preact boundary use explicitly defined DOM IDs and standard boolean properties (`aria-expanded={open}` rather than `aria-expanded={open ? 'true' : 'false'}` if possible, though explicit strings work reliably too in Preact).
