## 2024-07-04 - Overlapping Early Network Requests and Array Promise Mapping
**Learning:** In Astro API routes with sequential heavy operations (e.g., calling slow network services like ZimaOS gateway combined with multiple external file checks like process IDs and server ports in a loop), initiating the network call early as an unawaited Promise enables it to overlap with the subsequent sequential synchronous code or DB calls. However, an unawaited Promise can lead to unhandled rejection crashes if it fails early.
**Action:** Attach a dummy detached `.catch(() => {})` to early unawaited Promises to prevent server crashes, then `await` it later inside a try-catch block where the resolved value or error is actually handled. Furthermore, use `Promise.all` alongside array mapping (`map`) to initiate multiple independent I/O promises inside loops concurrently, and iteratively `await` them afterward to retain deterministic order when assembling responses.
