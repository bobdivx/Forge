## 2024-05-24 - [CRITICAL] Prevent Command Injection via execSync
**Vulnerability:** Found a critical command injection vulnerability in `src/pages/api/docker-logs.ts` where unsanitized user inputs (`containerId` and `tail`) were directly concatenated into a string passed to `execSync("docker logs...")`. This allows malicious actors to inject shell commands using characters like `;` or `|`.
**Learning:** Shell evaluation via `execSync` combined with unsanitized API parameters inherently creates critical risks. Even minor utility API routes must enforce strict parsing boundaries between commands and user-provided arguments.
**Prevention:** Do not use `execSync` or `exec` for system calls. Instead, use `execFile` (or its promisified version `execFileAsync`) and pass user inputs explicitly within an argument array to completely bypass shell interpretation. Additionally, always validate parameters strictly via regex (e.g. `/^[a-zA-Z0-9_.-]+$/` for Docker identifiers) and sanitize error messages to prevent leaking credential information (`error.message.replace(/https:\/\/[^@]+@/g, 'https://***@')`).
