## 2025-02-14 - CRITICAL Command Injection in API Endpoints via execSync
**Vulnerability:** A critical command injection vulnerability was discovered in `src/pages/api/docker-logs.ts` where unvalidated URL search parameters were interpolated into a string and executed using `execSync`. A similar (though less direct) vulnerability existed in `src/pages/api/forge-logs.ts`.
**Learning:** The use of `execSync` with string interpolation makes it extremely easy to accidentally introduce command injection vulnerabilities when parameters are sourced from user input (like URL parameters). Furthermore, synchronous child process methods block the Node.js event loop, severely degrading API performance.
**Prevention:** Never use string concatenation or interpolation when building shell commands. Always use asynchronous methods like `execFile` or `spawn` that accept an array of arguments for process execution. This isolates the command arguments from the shell parser, preventing command injection attacks and maintaining optimal event loop throughput.
