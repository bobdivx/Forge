## 2025-05-02 - ARIA Labels on Swarm Command Buttons\n**Learning:** The Swarm Command buttons on AgentCards were icon-only and relied solely on the `title` attribute, which isn't always reliably announced by all screen readers in the same way an `aria-label` is. Adding `aria-label` mirrors the `title` intent and guarantees screen reader accessibility for core actions.\n**Action:** Ensure that all icon-only buttons in the application receive an `aria-label` matching their `title` or describing their core action.
